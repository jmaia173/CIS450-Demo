4. HOW PANORAMA STITCHING WORKS (what I learned)
------------------------------------------------------------------------------
The OpenCV Stitcher pipeline, roughly:
  1. Detect features (keypoints/descriptors) in every image.
  2. Match features between image pairs and compute how confident each pair
     match is.
  3. Drop images whose matches are too weak to connect to the main group
     (this is where panoConfidenceThresh matters).
  4. Estimate camera rotations for the connected images; wave correction
     straightens the horizon across a wide panorama.
  5. Warp images onto a common surface, find seams, and blend them.
Parameters that mattered:
  - panoConfidenceThresh: lower values let weaker-overlap images join.
    1.0 dropped images; lower values kept more.
  - mode: PANORAMA (rotation about a point) vs SCANS (affine, flat scenes).
  - wave correction: on/off changes how the horizon bends.
  - image size/registration resolution: bigger inputs can give the feature
    detector more to work with.
  - image order: I pass the images left to right so neighbours overlap.
Why hierarchical stitching can help: each merge only has to match a couple of
images, and the merged result then acts as one bigger image with more features
for the next merge.
